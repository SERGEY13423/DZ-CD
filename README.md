Данный проект показывает одно из физических явлений на двигателе Юнити, явление называется ускорение свободного падения и обозначатется как g =9.8 м/c. Был создан объект, который падает при запуске симуляции прям лицом к камере. Ускорение свободного падения используется во множестве различных физических явлениях, а после и в формулах.
